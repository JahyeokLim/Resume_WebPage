# 사이트 개요

## 소개
임베디드 소프트웨어 개발자 임재혁의 이력을 소개하는 웹 사이트

## 사이트 목적
이력서 제공 + 참여했던 프로젝트 소개

## 누구를 위한 사이트인가
- 내가 지원한 회사의 면접관
- 나를 궁금해 하는 회사의 면접관

## 무엇을 하는 곳인가
- 내가 지금까지 했던 프로젝트(이력)를 한 눈에 볼 수 있는 곳

## 디자인/톤
- 미니멀 & 프로페셔널한 톤 (선정 시안: 스위스 그리드 스타일 — 12컬럼 그리드, 절제된 헤드라인, 화이트 베이스 + 포인트 컬러)
- PC / 모바일 반응형 대응 (모바일에서도 열람 가능해야 함)
- 라이트/다크 모드 지원 (헤더에 테마 전환 버튼, 선택值은 로컬에 저장해 재방문 시 유지)

## 언어
- 한국어 + 영어 다국어 지원 (언어 전환 기능 필요)

## 메뉴 구성

### 1. 홈 (`/`)
- 기본 프로필: 이름, 사진, 한 줄 소개, 연락처(이메일 등), 링크(GitHub/LinkedIn 등)
- 학력/경력 타임라인
- 기술 스택 요약
- 이력서 PDF 다운로드 버튼

### 2. 프로젝트 소개 (`/projects`, `/projects/<id>`)
- 목록 페이지: 프로젝트 카드 리스트
- 상세 페이지: 카드 클릭 시 이동, 다음 항목 포함
  - 개요 / 진행 기간 / 본인 역할·담당 범위
  - 사용 기술 스택 (태그 형태)
  - 시스템 구조/아키텍처 설명 (블록다이어그램 등 이미지 포함)
  - 이미지/동영상 첨부 (제품 사진, 시연 영상, 회로도 등)

### 3. 문의하기 (Contact)
- 방문자가 메시지를 보낼 수 있는 문의 폼 (이메일 발송 연동 필요)

## 보안/공개 범위
- 사내보안이 필요한 프로젝트는 회사명·제품명·세부 스펙 등을 가리고, "◯◯ 기술을 사용한 임베디드 시스템" 수준으로 추상화하여 소개
- 프로젝트 데이터 입력 시 공개 가능 여부/추상화 수준을 항목별로 표시해 관리

## 데이터 관리
- Django Admin + DB로 프로젝트 데이터 관리 (동적 입력/수정 가능)
- 관리자 진입점: 사이트 방문자에게는 일반 공개 사이트로만 보이며, 별도 로그인/게스트 화면 없음
  - 푸터 등 눈에 띄지 않는 위치에 작은 "Admin" 링크 배치 → 클릭 시 Django Admin(`/admin/`)으로 이동
  - Django 기본 로그인 화면에서 관리자 계정으로 로그인 → Django Admin에서 이력/프로젝트 데이터 CRUD
  - 일반 방문자(면접관 등)는 로그인 절차 없이 바로 콘텐츠 열람 가능

## 배포
- 무료/저비용 호스팅 서비스 사용 예정 (예: Render, PythonAnywhere 등 추후 확정)

## 사용할 기술
- Django, Python 등
